# 💼 Job Seeker Application – Full Stack Platform

Job Seeker Application is a **full-stack web application** developed as a **personal job application and management platform**.  
The system allows **job applicants to register, log in, submit applications, provide feedback, and ask questions**, while **Admin users can monitor applicants, view analytics, and manage responses** through a secure dashboard.

---

## 🚀 Key Features

### 👤 Applicant Module
- User registration and secure login
- Submit personal job application details
- View application status
- Submit feedback and questions
- Secure access to personal profile and responses

### 🛠️ Admin Module
- Admin authentication and role-based access
- View total number of registered applicants
- Access complete applicant profiles and applications
- Review user feedback and questions
- Respond to applicant queries from admin panel
- Monitor application activity through dashboard

## 🔐 Authentication & Authorization
- JWT-based authentication
- Role-based access control (Admin & Applicant)
- Secure API endpoints using DRF permissions
- Password hashing and token-based sessions

---

## 🌐 Application Architecture
- Decoupled frontend and backend architecture
- RESTful APIs for frontend–backend communication
- Scalable and maintainable modular design
- Clean separation of concerns using DRF views, serializers, and models
